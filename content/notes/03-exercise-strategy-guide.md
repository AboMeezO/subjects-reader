# Action Pack 12 - Exercise Strategy Guide

## Verb-form questions
1. Underline the time clue.
2. Decide present/past/future.
3. Decide simple/continuous/perfect/passive.
4. Check subject agreement.

## Rewrite questions
1. Keep the exact meaning.
2. Identify the requested grammar clue.
3. Change only the grammar structure.
4. Check tense, pronouns, articles, and word order.

## Reading comprehension
1. Skim title and pictures.
2. Read questions before detailed reading.
3. Underline keywords.
4. Find synonyms in the text.
5. Answer from the text, not from memory.

## Writing tasks
1. Identify the required writing type.
2. Make a paragraph plan.
3. Use unit vocabulary.
4. Include the target grammar where natural.
5. Check grammar, spelling, punctuation, and paragraphing.
